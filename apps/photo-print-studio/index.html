Cetak pada skala 100%

Agar ukuran foto tepat (mis. 3×4 = 30×40 mm), atur dialog cetak browser:

  1. Ukuran kertas: (sesuai media)
  2. Skala: pilih 100% / Default — JANGAN “Fit to page / Sesuaikan ke halaman”.
  3. Margin: pilih None / Tidak ada.
  4. Orientasi: otomatis mengikuti kertas.
  5. Aktifkan Background graphics bila tersedia.
  6. Di dialog printer (driver), nonaktifkan “Fit/Shrink to printable area”.
Setelah mencetak, ukur satu foto dengan penggaris untuk memastikan skala 100%. Untuk hasil paling presisi gunakan Export PDF.
